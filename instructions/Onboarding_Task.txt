Editor 
Project Title 
Universal DB Editor (SQLite, PostgreSQL, MongoDB) 
Background 
Developers, analysts, and support engineers frequently work with multiple database 
technologies. Existing database management tools are often database-specific, expensive, 
overly complex, or require separate installations. 
The goal of this project is to build a web-based database editor that allows users to connect to 
different database systems through a single interface and perform common database 
management tasks. 
This project is intended as an onboarding assignment to evaluate an intern’s ability to: 
●​ Design scalable software architecture 
●​ Work with multiple database technologies 
●​ Build secure backend APIs 
●​ Develop intuitive frontend interfaces 
●​ Handle real-world edge cases 
●​ Write maintainable code 
 
Objective 
Build a browser-based database editor supporting: 
1.​ SQLite 
2.​ PostgreSQL 
3.​ MongoDB 
The application should allow users to connect to databases from: 
●​ Local database files 
●​ Uploaded files 
●​ Direct connection strings/URLs 
●​ Remote database servers

Stretch Goal (What separates excellent 
interns) 
Implement a provider-based architecture: 
DatabaseProvider 
    ├── SQLiteProvider 
    ├── PostgreSQLProvider 
    └── MongoProvider 
so adding a new database requires implementing only a new provider and registering it in the 
system. 
This demonstrates understanding of abstraction, extensibility, and production-grade software 
design rather than simply building a CRUD application.
